About

This site is a client-side API explorer and static mirror for your local backend. It attempts to discover endpoints from the root response, render list/detail views for array endpoints, and auto-generate forms for POST/PUT based on returned object keys.

Note: For the explorer to call your backend from the browser the backend must allow CORS or the page must be served from the same origin/network.

Made for Shay-21 • Static frontend explorer
Run locally: python3 -m http.server 3000
